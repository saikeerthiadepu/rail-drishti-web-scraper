# rail-drishti-web-scraper
Python web scraping project developed in 2023 to extract Commodity-wise and Zone-wise freight revenue data from the Rail Drishti portal and export the results to Excel using Selenium, BeautifulSoup and Pandas.
# Rail Drishti Web Scraping Project

## 📌 Project Overview

This project was developed in 2023 to scrape freight revenue
data from the Rail Drishti portal of Indian Railways.

The objective was to extract:

- Commodity-wise freight revenue data
- Zone-wise freight revenue data

The extracted data was processed and exported to an Excel file
for further analysis.

## 🛠️ Technologies Used

- Python
- Selenium
- BeautifulSoup
- Pandas
- Excel

## 🔄 Project Workflow

Rail Drishti Website
        ↓
Selenium
        ↓
BeautifulSoup
        ↓
Extract Tables
        ↓
Pandas
        ↓
Excel Output

## 📊 Data Extracted

### Commodity-wise Data

The scraper extracted:

- Commodity
- Current Year
- Previous Year
- Change %

### Zone-wise Data

The scraper extracted:

- Railway Zone
- Current Year
- Previous Year
- Change %

## 📁 Output

The extracted data was saved into an Excel workbook containing
separate sheets for:

- Commodity-wise data
- Zone-wise data

## ⚠️ Note

This project was developed in 2023 using the Rail Drishti webpage
available at that time.

The original webpage URL used for this project is no longer
available in its previous form and currently returns a 404 page.
Therefore, the scraper may not work against the current website
without modification.
